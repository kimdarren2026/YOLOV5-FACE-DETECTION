# YOLOv5 Face Detection

Real-time face detection application using YOLOv5 and OpenCV.

## Features

- Real-time webcam face detection
- YOLOv5 object detection model
- OpenCV integration
- Python-based implementation

## Technologies

- Python
- YOLOv5
- OpenCV
- PyTorch

## Use Case

This project demonstrates computer vision techniques for real-time face detection and monitoring applications.
